# CouchKraft — editorial frontend redesign

Frontend-only prototype of a premium furniture e-commerce experience for [CouchKraft](https://couchkraft.in).

There is **no backend**, database, authentication, or payment processing. The catalogue, prices and promotions are mock data. The cart and wishlist persist in `localStorage` on this device only. Checkout is intentionally disabled.

## Run locally

```bash
cd "couch kraft"
npm install
npm run dev
```

Then open the URL Vite prints (usually `http://localhost:5173`).

## Demo coupon

Use `WARM10` in the bag for a 10% demonstration discount. It is not a live offer.
